# Contributing Feedback

Thank you for helping improve sdlc.work!

## Guidelines

- **Search first** — your feedback may already exist
- **One issue per topic** — keeps discussion focused
- **Be specific** — include steps, screenshots, or examples where possible
- **Vote** — use thumbs-up on existing issues instead of "+1" comments

## Labels

| Label | Meaning |
|-------|--------|
| `customer-feedback` | Submitted via sdlc.work chat |
| `feature-request` | New capability |
| `bug` | Something broken |
| `improvement` | Enhance existing feature |
| `accepted` | Moved into development |
| `needs-info` | Waiting for more details |
