# SDLC Feedback

Customer feedback for [sdlc.work](https://sdlc.work) — the AI-powered software development platform.

## How to Submit Feedback

1. **Check existing issues** to avoid duplicates
2. **Create a new issue** using one of our templates:
   - **Feature Request** — suggest a new capability
   - **Bug Report** — something isn't working as expected
   - **Improvement** — enhance an existing feature
3. **Vote** on existing issues with a thumbs-up reaction

## What Happens Next

Our team reviews all feedback regularly. Issues may be:
- **Accepted** — moved into our development pipeline
- **Needs Info** — we'll ask follow-up questions
- **Declined** — with an explanation of why

## Automated Feedback

Feedback submitted through the sdlc.work chat interface is automatically created as an issue here.
